# Notrufanlagen Wartung – V26

V26 erweitert die bisherige mobile Wartungsanwendung um eine vollständige Admin-Zentrale.

## Admin
- Admin-Login
- Benutzer anlegen
- Benutzer bearbeiten
- Rolle Techniker/Administrator ändern
- Passwort zurücksetzen
- Benutzer aktivieren/deaktivieren
- Benutzer ohne Historie löschen
- Benutzer mit Historie werden aus Dokumentationsgründen nur deaktiviert
- Übersicht aller Wartungen
- Techniker, Haus, Station, Prüfungsart und Status sichtbar
- Fortschritt pro Wartung mit Zimmerzähler und Prozentanzeige
- NOK-Zimmer und NOK-Komponenten sichtbar
- Suche und Filter
- Read-only Detailansicht einer Wartung
- Digitale Unterschrift und PDF eines abgeschlossenen Protokolls einsehbar

## Rechte
Techniker können nur ihre eigenen Wartungen bearbeiten. Admins können alle Wartungen ansehen, aber keine Prüfergebnisse verändern. Abgeschlossene Wartungen sind gesperrt.
